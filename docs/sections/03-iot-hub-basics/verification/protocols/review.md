## 変更と出典

03-05にMQTT・AMQP・HTTPSの比較を追加し、03-06のSDK説明から独立させた。選択場面、C2Dメッセージ受信、TLS接続で扱うデバイスID、ポートを同じ行で比較する。比較内容はMicrosoft Learn MCPで取得した公式本文と照合した（[通信プロトコルの選択](https://learn.microsoft.com/ja-jp/azure/iot-hub/iot-hub-devguide-protocols)）。

WebSocket経由の443番ポートをHTTPS方式と混同しない留保と、IoT HubのMQTT対応が汎用MQTTブローカーと同じではない留保を投影本文に残した。スライド下端にクリック可能な出典を置き、ノートには完全なURLを保持する（[ポート番号](https://learn.microsoft.com/ja-jp/azure/iot-hub/iot-hub-devguide-protocols#port-numbers)、[MQTTサポート](https://learn.microsoft.com/ja-jp/azure/iot-hub/iot-mqtt-connect-to-iot-hub)）。

比較に120秒、SDKに90秒を配分した。登録・資格情報・確認問題を前回から各30秒短縮し、25分の章配分とアジェンダ全体は変更していない。後続ページ番号と原稿・アウトラインの参照を同期した。

- [validation.json](validation.json): 12枚、1500秒、全投影本文の一致、ノートと出典、PowerPoint再オープン後の照合、文字枠のはみ出し0件。原稿・テンプレート・出力のSHA256を記録。

- 生成スクリプトと変更した原稿のエディター診断にエラーなし。
- 実機デモ、実ログ取得、25分の発話実測、実会場での投影、他のOS・レンダラーでの表示は未検証。出典はリンク構造と原稿一致を検査しており、全リンク先へのアクセス試験を意味しない。
