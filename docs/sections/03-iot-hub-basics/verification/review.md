# 第3章 PowerPoint描画レビュー

## 対象と方法

- 実施日: 2026-09-08。対象は [PowerPoint](../03-iot-hub-basics.pptx) と [PDF](../03-iot-hub-basics.pdf)、原稿は [slide.md](../slide.md)。11枚・25分程度。
- [テンプレート本文](template-body.png) を読み取り専用で描画し、960×540pt、Yu Gothic UI、26ptのタイトル、タイトル位置と罫線を確認。本文スライドを複製し、固有のダミー内容を除去して組み立てた。
- PowerPointで全11枚を1600×900pxのPNGに描画。前半6枚・後半5枚を2つの読み取り専用サブエージェントが実画像で確認した。
- 修正後は、変更のあった03-01〜04と03-07〜11を読み取り専用で再確認。03-05・06は初回の画像レビュー後にレイアウト変更なし。
- 内容の技術的な裏付けは [原稿レビュー](../review.md) を引き継ぐ。画像レビューは仕様の再調査ではなく、説明の自立性・意味の誤読・可読性・テンプレート適合の確認。

## 検査の範囲

生成直後とPowerPointで再オープンした後に、11枚の全投影本文、タイトル、ノート、出典リンクを照合。文字枠と表セルの測定では、許容差2ptを超えるはみ出し候補なし。原稿・テンプレート・出力のハッシュを [validation.json](validation.json) に保存する。PPTX内部のXML・タイトル・ノート・ネイティブ図形・リンク・ダミー文字は [structure.json](structure.json) に別記録する。

出典欄は配布時に参照する補足として小さめに配置し、重要な認証制約・配送前提・未確認範囲は通常の本文サイズで残した。画像レビューはAIサブエージェントによるもので、人間の受講者テストや公式承認を意味しない。実機デモ、25分の発話実測、別環境での表示は未検証。
